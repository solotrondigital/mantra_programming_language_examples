# Mantra Examples

Examples consolidated from the Mantra programming language and Mantra website projects.

## Directories

- [`programming_language/`](programming_language/) contains compiler, language, WebAssembly, mobile, and AI examples from `mantra_programming_language/examples`.
- [`website/`](website/) contains tutorials and complete application examples from `mantra_website/mantra_web/examples`.
- Environment templates use `.env.example` names. Copy the template you need to `.env` and provide local credentials before running an example.

The two source projects had overlapping numbered tutorials. They remain under their original project directories so neither version is lost.

Build outputs, platform caches, editor metadata, and local environment files are excluded. Example databases and source assets are retained.
